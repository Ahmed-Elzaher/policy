# صفحات السياسات القانونية لتطبيق MatchIn

موقع متكامل مبني بـ React و Vite لعرض:
- **سياسة الخصوصية (Privacy Policy)**: متوافقة مع متطلبات Google Play و App Store والأذونات وخدمات الطرف الثالث (Firebase, AdMob, Google Sign-In).
- **الشروط والأحكام (Terms & Conditions)**: قواعد الاستخدام، حقوق الملكية الفكرية، ومسؤوليات الحساب.
- **حذف الحساب والبيانات (Delete Account)**: استيفاء معايير Google Play Data Safety بشكل كامل.
- **الدعم والتواصل (Support & Contact)**: قنوات التواصل والبريد الرسمي.

يدعم الموقع اللغتين العربية (RTL) والإنجليزية (LTR) بالكامل بتصميم متناسق مع هوية MatchIn.

## التشغيل المحلي
```bash
npm install
npm run dev
```

## بناء المشروع للإنتاج
```bash
npm run build
```

## الروابط المطلوبة في Google Play Console / App Store
- **Privacy Policy**: `https://YOUR-DOMAIN/privacy`
- **Terms**: `https://YOUR-DOMAIN/terms`
- **Delete Account (Data Safety URL)**: `https://YOUR-DOMAIN/delete`
- **Support**: `https://YOUR-DOMAIN/support`
